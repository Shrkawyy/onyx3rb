واجهة ONYX للعبة 3rb.io

إضافة متصفح مستقلة تظهر فوق اللعبة الأصلية، لعرض FPS وتسجيل الشاشة والتخصيص. لا تتحكم في بوتات أو اتصالات اللعبة.

تركيب ONYX على Chrome أو Edge

  1. حمّل المشروع من GitHub ثم افتح مجلد extension بعد فك الضغط.
  2. ادخل إلى chrome://extensions أو edge://extensions.
  3. فعّل وضع المطور واضغط Load unpacked واختر المجلد extension.
  4. افتح اللعبة الرسمية واختر FFA والسيرفر من قائمة اللعبة.

نسخة Tampermonkey

يمكنك تثبيت ملف onyx-3rb.user.js بعد تثبيت Tampermonkey. لا تشغّلها مع امتداد المتصفح في نفس الوقت.

حول المالتي والبوتات

هذا المشروع لا يوفر مالتي أو بوتات في FFA ولا يضمن الاتصال بكل السيرفرات. العميل الرسمي هو المسؤول عن عرض السيرفرات واختيارها. شروط 3rb تمنع تشغيل بوتات وبرامج تؤثر في اللعب؛ راجع شروط الاستخدام.

مشروع مستقل غير تابع لإدارة 3rb.io، ولا يتضمن علامة اللعبة أو محركها.
