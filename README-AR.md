# ONYX 3RB Companion — مشروع GitHub كامل

هذه نسخة مستقلة من إضافة متصفح لـ **3rb.io**، وليست تحويلًا لمحرك بوتات ONYX الخاص بـSenpa.

## ما يعمل

- تحميل لوحة ONYX فوق **الموقع الرسمي** 3rb.io (Chrome وEdge باستخدام Manifest V3، أو Tampermonkey).
- التعامل مع واجهة اللعبة الأصلية، ومنها قائمة اختيار مود FFA وأي سيرفرات ظاهرة داخل اللعبة، **بدون أي اتصال شبكي مستقل بالنيابة عن اللاعبين**.
- إظهار FPS الخاص بعرض الصفحة ومدة الجلسة، وإخفاء اللوحة وتغيير موضعها وشفافيتها وحجمها.
- لقطات شاشة وتسجيل فيديو لعلامة التبويب أو النافذة عند منح إذن المشاركة عبر المتصفح.
- اختصار Ctrl+Shift+O لإظهار/إخفاء اللوحة.
- لا يعتمد على محرك Senpa أو ملفات WASM أو تسجيل حسابات البوتات أو مفاتيح خاصة.

## ما لا يعمل / غير موجود

- **لا يوجد** اتصال مستقل إلى سيرفرات 3rb، أو اكتشاف برمجي لقائمة كل السيرفرات، أو تبديل تلقائي بينها.
- **لا يوجد** إنشاء حسابات بديلة أو مالتي أو بوتات تحرك خلايا داخل FFA؛ لم يتم التحقق من واجهة برمجية تسمح بذلك، وشروط 3rb الحالية تمنع البوتات والبرامج التي تغيّر اللعب: https://3rb.io/terms
- لا يمكن ضمان أن **جميع** السيرفرات متاحة؛ تظهر السيرفرات المتاحة داخل قائمة العميل الرسمي، بحسب حالة اللعبة.

## طريقة تشغيل الإضافة في Chrome / Edge

1. فك الضغط وافتح مجلد `extension`.
2. ادخل إلى `chrome://extensions` أو `edge://extensions`.
3. فعّل **Developer mode** ثم **Load unpacked** / **تحميل غير مضغوط**.
4. اختر **مجلد `extension` نفسه** (الذي يحتوي `manifest.json`).
5. افتح https://3rb.io/ وأكمل تحقق الموقع بطريقة طبيعية؛ ستظهر لوحة ONYX.
6. اختر `FFA` والسيرفر المطلوب من القائمة **الأصلية** للعبة، ثم اضغط Play.

## Tampermonkey (بديل عن إضافة المتصفح)

- افتح `userscript/onyx-3rb.user.js`، وانسخ الكود إلى سكربت جديد داخل Tampermonkey واحفظه.
- عطّل سكربت ONYX / Senpa القديم حتى لا تتداخل الواجهات.
- لا تشغّل Tampermonkey وامتداد المتصفح معًا؛ كليهما يضيف اللوحة نفسها.

## إنشاء مستودع GitHub جديد

ارفع مجلدات `extension`, `userscript`, `tools`, `tests` والملفات `index.html`, `package.json`, `README-AR.md`, `vercel.json` إلى **جذر المستودع**. إن أردت صفحة دليل عامة فاختر المستودع عند استيراد مشروع Vercel، واضبط Framework Preset = Other (هذه صفحة ثابتة فقط).

> **ملحوظة:** نشر الملفات على GitHub أو Vercel لا يجعل بوتات 3rb تعمل؛ الإضافة تعمل محليًا في المتصفح واللعبة تعمل من موقعها الرسمي.

## بناء واختبار

يتطلب Node.js 18+، ولا يحتاج حزم npm خارجية.

```bash
npm run check
```

يقوم الأمر بتوليد نسخة Tampermonkey من ملفات الامتداد وإجراء اختبارات سلامة على الحزمة، **ولا يختبر البوتات أو اتصال سيرفرات 3rb الحية**.
